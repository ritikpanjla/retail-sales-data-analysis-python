# Retail Sales Data Analysis using Python

## Project Overview
This is a beginner-level data analysis project using Python. The project explores retail sales data to identify sales trends, best-selling products, top-performing categories, and city-wise revenue.

## Objectives
- Calculate total revenue and quantity sold.
- Identify best-selling products.
- Analyze sales by category and city.
- Explore monthly sales trends.
- Visualize sales data using charts.

## Tools & Libraries
- Python
- Jupyter Notebook
- Pandas
- Matplotlib

## Analysis Performed
- Basic data exploration
- Sales aggregation using GroupBy
- Sorting and ranking products
- Category-wise revenue analysis
- City-wise sales analysis
- Monthly sales trend analysis
- Data visualization (Bar Chart, Line Chart, Pie Chart)

## Key Findings
- Total Revenue: 27,25,010
- Total Quantity Sold: 325
- Top Selling Product: Mouse (75 units)
- Highest Revenue Category: Electronics
- Highest Sales City: Delhi
- Highest Sales Month: April

## Dataset
The dataset contains 80 records of sample retail transactions and 8 columns.

## Conclusion
This project helped me practice Python-based data analysis, data aggregation, sorting, and visualization, while extracting useful business insights from sales data.
